# lecture-video-clips

讲座视频切片制作技能（WorkBuddy Skill）。

把完整讲座视频自动制作成 1 分 30 秒的话题切片：标题页片头 + 完整话题，每个切片含横屏版、竖屏版（完整画面居中 + 模糊背景，保留台标/logo）及横竖屏标题页封面（JPEG）。

## 文件

- `SKILL.md` — 技能主文件：核心规则、前置检查、6 步制作流程、已知陷阱
- `references/ffmpeg-templates.md` — 全部 ffmpeg 命令模板（横屏/竖屏/封面/静音检测/归档）

## 安装

复制到 `~/.workbuddy/skills/lecture-video-clips/`（用户级）或 `.workbuddy/skills/lecture-video-clips/`（项目级）。
